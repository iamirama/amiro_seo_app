## 📌 این پروژه چیست؟

**Amiro SEO** یک ابزار آنالیز سئوی تکنیکال رایگان‌محور است که سایت را کرال می‌کند، هر یافته را توضیح می‌دهد و یک گزارش کاملاً آفلاین تولید می‌کند. APIهای سئوی پولی **اختیاری** هستند — اگر ارائه‌دهنده‌ای متصل نباشد، هیچ داده‌ای به‌صورت مصنوعی پر نمی‌شود.

این پروژه برای توسعه‌دهنده‌ها و متخصصان سئو ساخته شده که می‌خوان آنالیز‌های شفاف و مبتنی بر داده واقعی داشته باشن، بدون هزینه‌های پنهان.

```
┌─────────────────────────────────────────────────────────┐

│ ┌─────────────┐ ┌─────────────┐ ┌─────────────────┐    │
│ │ Audit UI    │ │ Settings    │ │ Report Viewer   │    │
│ └─────────────┘ └─────────────┘ └─────────────────┘    │
└──────────────────────────┬──────────────────────────────┘
                           │ (TanStack Query / Router)
┌──────────────────────────▼──────────────────────────────┐
│ Server (Next.js API / RPC)                              │
│ ┌─────────────┐ ┌─────────────┐ ┌─────────────────┐    │
│ │ Audit       │ │ Auth        │ │ Provider        │    │
│ │ Engine      │ │ (Better)    │ │ Connectors      │    │
│ └──────┬──────┘ └──────┬──────┘ └────────┬────────┘    │
│        │               │                  │             │
```

- **موتور آنالیز** – URL هدف را واکشی، DOM را با Cheerio پارس و مجموعه‌ای از قوانین بررسی را اجرا می‌کند.
- **کانکتورهای ارائه‌دهنده** – ماژول‌های جداگانه برای هر API سئوی پولی. **اختیاری** هستند و در نبود اعتبارنامه به‌درستی تخریب می‌شوند.
- **سریالایزر گزارش** – نتیجه آنالیز را به یک سند HTML مستقل با CSS و تصاویر اینلاین تبدیل می‌کند تا قابل ذخیره و اشتراک‌گذاری آفلاین باشد.
- **احراز هویت و پایداری** – سشن‌ها، آنالیز‌های ذخیره‌شده و کلیدهای رمزنگاری‌شده ارائه‌دهنده در PostgreSQL ذخیره می‌شوند.

## ⚡ شروع سریع

### 1️⃣ پیش‌نیازها

- **Node.js** `≥ 20` (یا `bun` / `pnpm`)
- **PostgreSQL** `≥ 14` (یا از **PGlite** برای دیتابیس امبدد بدون تنظیمات استفاده کن)
- یک مرورگر مدرن (Chrome, Firefox, Safari, Edge)

### 2️⃣ کلون و نصب

```
git clone https://github.com/iamirama/amiro_seo_app.git
cd amiro_seo_app
npm install
# or pnpm install
# or bun install
```

### 3️⃣ متغیرهای محیطی

یک فایل `.env.local` در ریشه پروژه بساز:

```
# ── Database ─────────────────────────────────
DATABASE_URL="postgresql://user:password@localhost:5432/amiro_seo"

# ── Auth (Better Auth) ───────────────────────
BETTER_AUTH_SECRET="a-32-character-secret"
BETTER_AUTH_URL="http://localhost:3000"

# ── Optional: AI Provider ────────────────────
OPENAI_API_KEY="sk-..."
AI_MODEL="gpt-4o-mini"

# ── Optional: Paid SEO APIs ──────────────────
# AHREFS_API_KEY=""
# SEMRUSH_API_KEY=""
# MOZ_ACCESS_ID=""
# MOZ_SECRET_KEY=""
```

> **نکته:** همه‌ی کلیدهای API پولی **اختیاری** هستند. اپ بدون آن‌ها هم اجرا می‌شود و آنالیز معنادار تولید می‌کند؛ فقط آن نقاط داده به‌عنوان «در دسترس نیست» علامت می‌خورند.

### 4️⃣ راه‌اندازی دیتابیس

```
# تولید فایل‌های مایگریشن (در صورت تغییر اسکیما)
npm run db:generate

# اعمال مایگریشن‌ها روی دیتابیس
npm run db:migrate

# یا پوش کردن مستقیم اسکیما (فقط توسعه)
npm run db:push
```

برای استفاده از **PGlite** (بدون نیاز به دیتابیس خارجی):
```
DATABASE_URL="pglite://./.pglite"
```

### 5️⃣ اجرای لوکال

```
npm run dev
```

سپس در مرورگر به **http://localhost:3000** برو.

برای اجرای بیلد پروداکشن به‌صورت لوکال:
```
npm run build
npm run start
```

## ☁️ دیپلوی

### Vercel (پیشنهادی)

پروژه برای **Vercel** آماده است. تنظیمات پیش‌فرض Next.js روی آن کار می‌کند.

1. کدت را روی GitHub پوش کن.
2. ریپازیتوری را در [Vercel](https://vercel.com/new) ایمپورت کن.
3. **متغیرهای محیطی** بالا را در داشبورد Vercel اضافه کن.
4. دیپلوی کن.

> **نمونه زنده:** [https://seoscan-seven.vercel.app/](https://seoscan-seven.vercel.app/)

### پلتفرم‌های دیگر

چون اپ از Next.js استاندارد و PostgreSQL استفاده می‌کند، روی هر پلتفرمی که Node.js و دیتابیس Postgres را پشتیبانی کند (Railway, Fly.io, Render, AWS و…) هم قابل دیپلوی است. فقط مطمئن شو که `DATABASE_URL` و `BETTER_AUTH_URL` برای محیط هدف به‌درستی تنظیم شده باشند.
